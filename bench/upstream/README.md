# Upstream datastore workloads

This directory retains source snapshots and ports selected public datastore contracts and one existing benchmark workload. Run correctness before collecting timings:

```sh
deno task test:upstream
BENCH_PREFLIGHT_ONLY=1 deno run --v8-flags=--expose-gc --allow-read --allow-env bench/upstream/store_bench.ts
BENCH_FORMAT=json deno run --v8-flags=--expose-gc --allow-read --allow-env bench/upstream/store_bench.ts
```

The final command measures all 18 cases. Run it alone after dependency preparation and other tests finish. Save raw stdout, stderr, runtime/host identities and source hashes under ignored `.tmp/reports/`. The standalone program emits workload metadata to stderr and native Mitata JSON to stdout. It does not create a complete source-guarded report by itself; a collector must preserve that provenance. Preflight mode executes the same correctness checks without invoking Mitata.

## Selection and adaptations

[`provenance.json`](./provenance.json) records exact repository commits, original paths, URLs, byte sizes and SHA-256 digests. Foreign executable source is stored with an inert `.txt` suffix; the content is unchanged. It is evidence and attribution, not executable repository code. Every retained project has its original license file. The snapshot hash establishes origin and integrity; it is not an assertion about our implementation.

The Store extension has 20 leaf cases: all 16 SPOG bound/wildcard masks, duplicate/deletion behavior, the RDFLib graph scenario, RDF4J filter behavior, and independent oracle mutations. Each mask checks exact outputs before and after delta reopen and compacted snapshot reopen. The backend is a borrowed `MemoryFileSystem`; these checks exercise segment serialization and index recovery, not disk durability, fsync, power loss or OS I/O.

The actual engine suite has 12 leaf cases: six scenarios for each of Oxigraph and Comunica. Expected terms and quads are hand-authored RDF/JS-shaped records. The fixture owns its engine and explicitly releases Oxigraph result wrappers, including getter-created child terms, independently of the production adapter's borrowed-resource contract. Assertion and teardown failures are both retained.

The retained [Oxigraph BSBM benchmark](./sources/oxigraph-oxigraph/js/test/store.bench.ts.txt) and [Comunica BSBM instructions](./sources/comunica-comunica/performance/benchmark-bsbm-file-10k/README.md) were evaluated but are **not adopted**. They require external BSBM data/generators, query mixes and result oracles. Oxigraph's workload additionally serializes XML results and maintains query/update state over 300 operations. Our eight-quad query fixture is derived from correctness tests and supplies no BSBM performance claim or duplicate query microbenchmark.

## Jena benchmark contract

The exact 315,148-byte Turtle fixture contains 7,744 unique default graph triples. Before timing, N3 parses it and a plain public-term tuple map determines independent set identity; native Dataset keys/indexes do not define expected cardinality. Every unique selector is checked against exact expected quad identity and multiplicity in all three lanes. Missing, duplicate, wrong graph and wrong literal oracle controls are retained in the correctness suite.

| Family | Bound fields       | Distinct selectors per operation | Consumed triples per operation |
| ------ | ------------------ | -------------------------------: | -----------------------------: |
| `S__`  | subject            |                              692 |                          7,744 |
| `_P_`  | predicate          |                               87 |                          7,744 |
| `__O`  | object             |                            3,380 |                          7,744 |
| `SP_`  | subject, predicate |                            5,837 |                          7,744 |
| `S_O`  | subject, object    |                            7,090 |                          7,744 |
| `_PO`  | predicate, object  |                            4,349 |                          7,744 |

Each family has three lanes: native Dataset synchronous iteration/count, N3 synchronous iteration/count, and Store asynchronous iteration/count over a borrowed MemoryFileSystem with a warm index. Parsing, index construction, `addAll` persistence writes, delta reopen and correctness checks occur outside timers. Every timed operation traverses every selector and consumes all matching quads; the final count reaches Mitata's `do_not_optimize` sink. Store timing includes async iteration and native term conversion where performed; it is not equivalent to a direct synchronous graph API in mechanism, though workload and consumed semantic outputs match.

Native Mitata timings are nanoseconds per **complete family operation**, not per selector or per triple. Derived consumed-triple throughput is `7,744 / (medianNanoseconds / 1e9)`; selector throughput uses the family's selector count. State those definitions when presenting rates. `.gc('inner')` invokes exposed collection before and after each batch in the pinned framework. Native timing statistics and any interpolated percentiles have their respective estimator definitions; do not relabel raw samples or invent p95.

No CPU profile, process RSS, retained-memory, wire traffic or allocation counter is collected by this program. Mitata optional heap observations are nonnegative heap deltas, including zero, normalized across batches, not total allocations/RSS; explicit post-batch GC timings are unnormalized nanoseconds and are not workload latency. No network or hosted datastore is involved. Machine-specific comparisons require the same fixture, consumed outputs, runtime, dependency pins, collector and quiet host; no universal throughput budget follows from these cases.

`provenance.ts` checks every copied source, corpus and license byte before and after consumption. The integration suite runs the same acquisition guard. Byte size, SHA-256, pinned source URLs and the complete snapshot file set must agree with the manifest; neither a modified input nor an unexplained extra snapshot can silently become workload authority.
